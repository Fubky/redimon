# v0.9 物种造型与验证

本轮延续 v0.8 的基因部件拼接，集中改进角色造型与物种辨识度。保留 18 个基因位点、遗传规则、体型分类和基因变化区间；未改战斗数值、捕获、存档格式或玩家现有进度。

## 体验入口

双击工程内的 `启动游戏.bat`，运行重新导出的 Windows 独立版。

- 标题 → 基因图鉴 → 五物种同色对照：所有角色的基因完全相同，切换纯剪影后仍可观察物种差异；支持行走预览。
- 标题 → 基因图鉴 → 打开形态工坊：20 个遗传组合示例、体型组合与 16 个其他位点调整、待机／行走／施法、部件拆解。
- 伙伴档案 → 部件与形态预览：使用伙伴基因的副本，不写入伙伴或存档。

## 美术与结构

| 物种 | 造型 | 动作 |
|---|---|---|
| 绒耳猫 | 收腰、颊毛、小口鼻、尖耳、细卷尾、独立喉毛 | 前后肢交替，耳尾轻摆 |
| 旅风犬 | 高肩深胸、长吻、胸鬃、蓬松刷尾、弯曲后跗关节 | 较长四肢迈步，前肢施法 |
| 团团鼠 | 直立梨形躯干、圆臀、杯状耳、门齿、细尾、大后足、小前爪 | 前爪收于胸前，双足同拍轻跳 |
| 苔尾蜥 | 扁长躯干、宽吻、叶脊、鳞片、分趾爪、叶状尾 | 低幅度伏地迈步 |
| 月纹蛇 | 盘绕躯干、S 形颈段、扁楔形头、腹部节片、鳍与月冠 | 颈身摆动；头部跟随颈段，保持连接 |

上左受光、底部冷色阴影、暖色腹面与细轮廓线贯穿所有部件。眼睛具有物种专属形状、眼睑、虹膜、瞳孔及高光，眨眼围绕眼睛自身中心缩放。前肢肩部与蛇颈根部使用开放轮廓减少拼接切口；远侧肢体着色较暗。花纹对比稍降低，保留底色、白斑和光泽基因对显示结果的影响。

`assets/creature_parts_v9/` 共 124 个独立透明 SVG：17 个躯干、15 个头型、15 个耳型、20 个尾型、8 个前后肢、15 个物种毛质外形、25 组眼睛、3 个挂饰和 6 个专属装饰／颈段。每只角色实际绘制 10–13 个独立部件，不生成或读取整角色贴图。

造型定义在 `tools/creature_species_shapes.py`，共享 SVG 光照与生成逻辑在 `tools/create_creature_parts.py`。运行 `python tools/create_creature_parts.py` 同步独立 SVG 与内嵌模板库 `scripts/creature_part_library.gd`。连接位置与物种比例见 `CreatureAssembly.FORMS`。旧 v0.8 SVG 和 v0.7 整角色图集仅保留为历史资料，排除在导出之外。

## 验证

Godot 4.7.2 八套回归测试全部通过，共 10,440 项：规则 4,907，UI 103，控制 444，遗传技能 557，战斗深度 3,572，运行与操作缓存 46，环境美术 70，部件系统 741。

新增／更新检查覆盖全部 124 个 SVG 的透明度和有效几何、相同基因下的五种躯干与眼形、物种骨架比例、前后肢差异、待机／行走／施法／攻击／受击的连接完整性、蛇头跟随颈部、鼠前爪高于后足、原有遗传变化、动画缓存、同色与剪影控件、预览不修改玩家基因。功能测试通过 Godot 控件与输入接口，不等同于系统鼠标录像测试。

实际渲染检查了五物种同色与剪影、行走、20 种基因形态、各物种放大预览、拆件、城镇、战斗 AP 预览、技能动画与标题。标题站位和高大形态卡片作了适配。截图为 `screenshots/species9_*.png`，24 张技能连续帧位于 `screenshots/animation_frames/`。

Windows 独立版重新导出为 `build/windows/GeneTrail.exe`，134,603,016 字节；直接运行 EXE 验证物种对照、20 种形态、标题、城镇、战斗与拆件六个场景，全部进程退出码 0，未出现脚本或素材加载错误。截图为 `screenshots/species9_packaged_*.png`。另通过原 `启动游戏.bat` 打开物种对照并生成 `screenshots/species9_launcher.png`，启动器返回 0。

性能使用同一台 NVIDIA GeForce RTX 3060 Laptop GPU、Compatibility / OpenGL 3.3，1440×960 逻辑分辨率、1296×864 窗口，固定种子，关闭 VSync；每场景预热 30 帧后采样 180 帧。两次采样时均未并行运行图形预览。

## 范围

当前仍为二维侧向部件骨架和左右翻转，没有新增完整八方向素材。本轮提高五个现有物种之间的结构差异，没有增加新物种数量。所有验证与截图使用 `diagnostics/appdata`，不写入真实玩家存档。
