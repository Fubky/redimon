# v0.8 基因部件拼接

## 运行方式

双击 `启动游戏.bat` 运行更新后的 Windows 独立版。

- 标题 → 基因图鉴 → 打开形态工坊：5 物种 × 4 种形态对照。同列保持同物种、同底色，突出结构差异；这 20 个示例不是预设立绘，也不是所有可能形态的上限。
- 点击一个示例，进入单体调整页。体型选择与 16 个其他位点滑条驱动实际角色渲染；可切换待机、行走、施法及部件拆解。
- 伙伴档案 → 部件与形态预览：复制当前伙伴的基因进行预览，所有控件只修改副本，实际伙伴、战斗属性与存档不变。

## 拼接结构

`assets/creature_parts/` 包含 72 个独立透明 SVG 部件：5 个躯干、15 个头型、15 个耳型、20 个尾型、4 套肢体、3 个毛领／甲片、5 组眼睛、鳍、冠饰和 3 个挂饰。文件都是单个身体部位，没有预绘的完整角色或固定姿态。

每个角色约 11–13 个实际绘制部件，四肢复用同一肢体素材，远侧使用较暗着色。蛇形使用盘身、颈段与鳍的结构。绘制顺序、局部缩放与连接位置由基因和物种共同决定。

| 基因 | 可见变化 |
|---|---|
| 体型 A／B | 紧凑、轻巧、厚重等躯干轮廓与整体尺寸 |
| 肩高 | 肢体长度、躯干离地高度及头部连接位置 |
| 骨量／肌肉 | 肢体粗细、胸腹体积和冠饰尺度 |
| 体长 | 躯干长宽、前后肢间距、尾部长度 |
| 脸型 | 直接选择不同头部轮廓与口鼻部件形态 |
| 耳型／尾型 | 选择不同独立部件，具有不同轮廓与关节 |
| 毛质 | 光滑、棱状毛领、蓬松外圈、甲片外形 |
| 底色／花纹／白斑／对比／光泽 | 部件内部染色、条纹、斑点、色块、腹部白斑与高光 |
| 瞳色 | 独立眼睛部件及虹膜颜色 |
| 共感 | 挂饰形状与装饰色 |
| 敏捷 | 迈步节奏 |

部件的局部变换组成连接层次：躯干 → 头 → 耳、眼、冠、挂饰；躯干 → 四肢、尾。动画分别改变四肢角度、头部姿态、耳尾摆动与眼睛开合；施法会抬前肢，眨眼只压缩眼睛部件。移动与战斗特效继续由既有 UnitMotion 驱动。

世界单位、HUD、图鉴预览、问答和标题共用 `CreatureAssembly`。标题背景只取原画的无人景观区域，前景角色也由运行时部件拼接。旧 `PixelCreatures` 渲染器已移除，`assets/art_v7/creatures.png` 仅保留作历史素材并从导出中排除。没有修改遗传算法、战斗数值或 v3 存档格式。

## 部件维护

源定义在 `tools/create_creature_parts.py`，运行 `python tools/create_creature_parts.py` 会生成可查看的 SVG 及 `scripts/creature_part_library.gd`。运行时库内嵌同一份 SVG 模板，保证导出的 EXE 不依赖开发目录读取 SVG 文本。颜色与花纹在第一次使用时栅格化为部件纹理，运行中绘制的仍是独立部件，未合成整角色贴图。

默认部件画布为 96×96，连接参考点为 (48,48)，尾巴使用 (64,48)。调整部件时可修改路径或 `creature_assembly.gd` 中的连接点；改变画布需同时更新绘制尺寸。

角色组合缓存上限 96，部件纹理缓存上限 512。地图加载时预热角色；普通行走和动画只更新连接变换，不重新栅格化 SVG。

部件检查覆盖所有 72 个 SVG 的透明度和有效绘制内容、同色轮廓差异、耳型更换不重绘无关身体部件、结构与表面位点变化、四肢交替动作、耳部连接稳定性、动画缓存复用、40 次真实遗传生成的部件选择，以及工坊操作不修改真实伙伴。

本次图形测试设备为 NVIDIA GeForce RTX 3060 Laptop GPU，Compatibility / OpenGL 3.3。1440×960 逻辑分辨率、1296×864 窗口，固定种子，关闭 VSync，每场景预热 30 帧后取 180 帧：

| 固定场景 | 平均帧耗时 | P95 |
|---|---:|---:|
| 城镇 | 2.83 ms | 3.24 ms |
| 战斗 | 2.38 ms | 2.76 ms |

结果见 `diagnostics/benchmark_parts8.log`。与 v0.7 记录的 GPU 不同，因此不直接做版本速度对比；这些数字也不代表所有设备与战斗负载。
