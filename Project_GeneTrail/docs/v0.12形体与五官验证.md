# v0.12 形体与五官验证

本轮按用户反馈重新处理怪物基础造型：头身比例、轮廓、面部布局、色块关系和部件连接。花叶沿用现有部件并缩小占比，没有增加新的装饰题材。所有角色仍由基因选择独立部件与骨架参数，当前部件总数保持 239。

## 实际修改

- 重新绘制 17 个身体形状、15 个头型、15 个耳型、8 个肢体、猫的四种尾形及蛇颈。头部靠近前胸，肩颈留出重叠区；前肢近端不描完整闭合线，以减少贴片接缝。
- 重新设计五物种的眼窝、瞳孔、高光和鼻嘴位置，保持三种遗传脸型与六种表情。猫采用宽颊短面，犬采用较饱满的前胸与圆钝口鼻，鼠采用圆颊梨形身体，蜥蜴采用圆头低重心，蛇采用弧形头与连续颈线。
- 眼形不再共用相同比例：猫较灵动，犬圆润，鼠偏圆形，蜥蜴横向展开，蛇较狭长且瞳孔更窄。所有眼嘴状态仍是独立透明部件，随游戏动作切换。
- 统一深蓝灰描边，增强主色与奶油色的分区，采用简洁的底部阴影。脸部保持安静的色块，遗传花纹主要落在身体和尾巴；白斑、对比、底色等基因仍影响可见外观。
- 保留体型、体长、骨量、肌肉和肩高的变化，同时调整它们映射到各物种骨架的比例。鼠的前爪和后足落点额外调整，避免被头身遮住。

开始界面 → 基因图鉴 → **怪物造型室**。可以切换“基础形体 / 完整造型”，查看关闭装饰后的轮廓；支持行走、施法、面部表情和遗传形态工坊。预览只操作副本，不改变真实队伍或存档。

## 源码与资源

- `tools/creature_form_refinement.py`：本轮身体、耳、肢体、尾与蛇颈轮廓。
- `tools/creature_portraits.py`：本轮头型、眉眼、口鼻和表情。
- `tools/create_creature_parts.py`：统一描边和阴影，输出 `assets/creature_parts_v12/` 及内嵌运行时 SVG 库。
- `scripts/creature_assembly.gd`：比例、连接点、配色、装饰显示和动画骨架。
- `scripts/botanical_workshop.gd`：保留内部类名兼容原有调用；用户可见名称改为“怪物造型室”。

旧部件目录留作历史参考，导出排除 v0.8–v0.11 的旧资源。真实角色继续使用 12–14 个部件，表情与部件预热缓存逻辑保持不变。

## 验证证据

Godot 4.7.2 八套回归共 **10,882 项通过，零失败**：规则 4,907、UI 103、控制 444、遗传技能 557、战斗深度 3,572、运行缓存 46、环境美术 70、角色部件 1,183。最后调整鼠的前后肢落点后，再次运行部件测试，1,183 项通过。

实际渲染检查包括基础形体、完整造型、行走、施法、六种表情、锐利脸型、20 种遗传形态、拆件、纯剪影、标题、战斗移动 HUD 与技能连续帧。功能测试确认透明资源、遗传变化、动作连接及缓存；视觉结果保存在 `screenshots/form12_*.png`。

Windows 独立版已重新导出，最终 EXE 为 **134,783,104 字节**。独立包的九种预览均返回 `PREVIEW_CAPTURE ... 0`，技能演出保存 24 张连续帧到 `screenshots/form12_packaged_animation_frames/`。原 `启动游戏.bat` 返回 0，并生成 `screenshots/form12_launcher.png`，内容为关闭装饰的基础形体预览。

本机固定场景性能：RTX 3060 Laptop GPU、Compatibility / OpenGL 3.3、1440×960 逻辑分辨率、1296×864 窗口，关闭 VSync，预热 30 帧、采样 180 帧。城镇平均 **3.38 ms / P95 4.24 ms**，战斗平均 **3.08 ms / P95 3.85 ms**；日志 `diagnostics/benchmark_form12.log`。

测试和预览均使用隔离的 `diagnostics/appdata`。真实存档未修改。最终图形预览没有脚本、加载或截图保存失败，仍有机器系统证书库读取提示；部分 headless 测试保留历史资源退出提示。此次没有制作八方向新视图，仍使用侧向骨架及左右翻转。
