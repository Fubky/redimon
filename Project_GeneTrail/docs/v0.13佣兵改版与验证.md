# v0.13 佣兵改版与验证

日期：2026-10-01。运行环境：Windows、Godot 4.7.2 stable、Compatibility / OpenGL 3.3。

## 实现范围

保留城镇自由行走、五域随机 TileMap、房间制战斗、100 AP 与超支延时、四人队伍、努力值和概率招募。当前包装为《帝国佣兵 · 血脉与契约》，使用神圣罗马帝国诸邦的幻想设定。

新增七族三职、自定义开局、可继承种族谱系、职业熟练度、基因培养难度、职业实战加成、借据主线及任务栏。主线负债 3000 金币，无自动扣款，支持分期与结清；任务包含五份清剿、五份护送，跟随地区解锁。

家系馆以推演下一代并快进到成年入团的方式保留遗传玩法。不同亚人种族可配对，保留近亲限制、床位与金币校验。职业与努力值不遗传。每个角色拥有遗传、种族和当前职业三部分技能池，携带上限四项。

开局的均衡、坚韧、以太、灵巧体质直接写入相关等位基因；实时预览职业需求倍率。骑士骨量 / 肌肉、法师共感 / 以太传导、游侠敏捷 / 肢体比例影响熟练度门槛。任意种族都能学习所有职业，切换保留已积累的职业经验。

## 角色表现

`tools/create_human_parts.py` 生成 49 个独立 SVG 与 `scripts/human_part_library.gd`。`HumanAssembly` 为唯一在地图、HUD、标题、自定义界面和角色名录中使用的人形渲染器。

帽子、头发、脸部、躯干、手臂、手掌、腿、脚、披风 / 翅膀、尾、角和武器分层装配。鱼人、蛇人的下半身替换人腿。翼人提供鹰、鸦、天鹅羽型；龙人均有鳞纹与蜥蜴尾，背部基因表达达到 60 时装配龙翼。牛、羊、鹿角和猫 / 犬特征按遗传表达切换。

转职只更换职业服装、帽子与武器，不会更改遗传面孔或翅膀配色。六种面部表情与动作纹理预缓存；行走、近战、施法、治疗、受击与倒下使用独立关节和现有演出系统。没有整个人物的固定立绘。缓存上限为 96 套外观、768 个部件纹理，动画期间不重建 SVG。

## 任务行为

- 同时最多三份委托、其中护送最多一份。任务系统在规则层检查地区解锁、接取上限、重复领取与支付条件。
- 清剿通过真实击败事件推进，同一敌人不可重复刷奖励。进度保存并可跨远征累积。
- 护送对象作为独立 `escort` 单位持久化，不占队伍名额。探索跟随、楼层转移、同房间集合、敌方选靶与攻击、友方治疗和守护都接入现有流程。
- 护送对象不占用时间轴回合；每个敌方行动结束后结算其异常。纯时间轴提前技能不能对没有行动回合的护送对象施放。
- 第 2 层楼梯交付要求存活且距离不超过六格。失败或提前撤离可以回城重接；目标完成后可继续挑战或返程领取佣金。

## 存档兼容

新格式 v4 增加职业、三职业经验、双种族谱系、债务、委托状态和护送对象。保留旧的用户目录名，不会因游戏改名找不到存档。旧 v1—v3 槽位沿用基因与资源，并按原种族编号转换为前五个亚人种族，缺失职业字段默认为骑士。默认债务为 3000，旧关卡进度与队伍不清空。旧物种专属技能不再适用时由当前技能池整理；建议读取旧档后检查一次配招。

当前职业装备属于外观与职业系统，没有独立的掉落装备、装备背包或实时世代年龄模拟。环境和音乐沿用已有资产；本次没有将全部地图重新制作成历史考据城市。
