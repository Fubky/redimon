# v0.5 设计与验证

## 战斗规则

8 属性：常态、炎、潮、森、岩、风、霜、灵。攻击克制为 2 倍、抵抗 0.5 倍、免疫 0 倍；双属性相乘。本系技能 1.5 倍。会心率 6.25%，会心伤害 1.5 倍。预计伤害是非会心命中时的值，命中率另外显示。

六类特性由物种、花纹、毛质基因共同表达：再生绒毛、厚甲、引水、引火、清醒、顺风。角色技能窗口显示自己的特性与效果。属性由物种和色素／光泽基因共同决定；遗传后重新表达。

灼伤降低物攻并持续掉血；中毒掉血；麻痹降低 AP 与速度；冻伤降低移动和速度；睡眠跳过一次行动，受伤会醒。净化及部分回复技能可解除异常。能力变化限 ±3 级，脱战清除，异常需净化或回镇治疗。

除基础爪击外多数技能每次行动仅用一次；进阶和强治疗需要等待两个行动轮次。技能冷却按自身开始行动递减。AP 50 分界与时间轴提前／延后仍然保留。进阶攻击可溅射邻格敌人，缠藤有吸血，守势抵挡一次攻击。AI 会评估克制、击倒、延迟、治疗和净化价值。

各基因仍有初阶／进阶分支；每个角色共 41 项可解锁条目（36 遗传项、4 共同战术、1 物种技能），同时携带最多 4 项。升级解锁后在城镇或探索中调整配招。

本次建立了接近宝可梦式组队取舍的规则层，但尚不能以一次实现证明达到完整宝可梦作品的内容量或长期平衡；物种仍为原有五类，后续平衡需靠持续实玩。

## 概率与副本

捕获沿用本作击败后邀请的表现形式，不使用精灵球。

| 物种 | 基础招募率 |
|---|---:|
| 绒耳猫 | 25% |
| 旅风犬 | 18% |
| 团团鼠 | 12% |
| 苔尾蜥 | 8% |
| 月纹蛇 | 5% |
| 重访守望者 | -8% |

最终率 = 基础 + 领队等级 + 徽记 + 高亲和 + 共鸣印记，限制为 0—95%。等级加成采用《空之探险队》资料中的区间：1—29 为 0%，30—39 为 5%，40—49 为 7.5%，50—98 为 12.5%，99 以上为 24.5%。参考 [Bulbapedia 招募机制](https://bulbapedia.bulbagarden.net/wiki/Recruitment#Explorers_of_Time,_Darkness,_and_Sky_2)。

本作自定规则：亲和表达 ≥80 加 5%，携带并施放共鸣印记加 10%，森林徽记加 5%／海岛徽记升级至 15%，两者不叠加。物种率是本作配置，并非对原作宝可梦逐一复刻。任意我方直接击倒可招募，没有照搬原作领队近身尾刀要求；持续伤害击倒不判定招募。首次守望者不可招募。每只怪物只有一次判定，失败不保留可重复尝试入口，随机数状态和判定标记随存档保存。

新档只开放森林，每区三层。第三层守望者被击败后才允许通关，并开放下一地；直接调用游戏规则也不能绕过锁定。旧档保留已有通关与角色，不清空存档。到达下一层不会补满 HP，回镇恢复。

## 美术与操作

新增主视觉、森林／城镇手绘地面、五主题地形、四座建筑、渐层角色、围巾饰物、粒子、元素色特效及属性标签。地图仍由 TileMapLayer 生成，手绘地面按连续坐标采样，避免每格重复贴图的棋盘效果。

WASD：探索走路／战斗镜头；点击行动角色后点击蓝色范围移动。快捷键 2—5 选择四技能，空格结束行动；Q 药草，E 设施／阶梯，C 镜头回正。悬停技能目标查看伤害、克制、命中、招募率。菜单的旅人手册提供战术与招募图鉴。

## 验证范围

`tools/verify.ps1` 执行地图／遗传／交易／存档规则测试、UI 输入测试、移动与相机测试、全部遗传技能测试和新增战斗深度测试。测试存档隔离于 diagnostics/appdata，正式存档不删除。

新增测试覆盖克制与双属性、天气、能力变化、特性免疫、冷却、净化、守势、招募印记不叠加、状态读档、旧档迁移、守望者封锁楼梯、五域递进解锁和 AI 决策。3,500 次招募样本为五物种各 700 次，结果约 25.9%、19.7%、11.4%、7.6%、5.1%。每次还验证重复击倒不会重复奖励或掷概率。

最终统计与运行日志见 diagnostics/verify_v5.log。画面检查为实际 Godot 渲染截图；尚未完成长时间平衡测试。发布 EXE 使用同一工程导出。
