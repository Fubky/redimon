# v0.10 面部表情与验证

本轮根据宝可梦风格的方向，使用原创 SVG 路径优化脸部的清晰度、亲和力和情绪表达。沿用五物种骨架与基因变化范围，保留所有遗传、技能、种族值和存档规则。

## 实际变化

- 眼睛采用近大远小的三分之四视角，扩大虹膜与深色瞳孔，用较重的上眼线和少量高光提高地图尺寸下的辨识度。
- 五物种保留不同眼形与口鼻：猫的短鼻与颊毛、犬的长吻、鼠的小鼻与门齿、蜥蜴的宽吻、蛇的扁头与月纹。脸型基因同时影响头部轮廓与眼形，瞳色基因控制虹膜。
- 从头部底图中分离嘴线；眼睛和嘴部都是独立的透明部件。各表情共享角色的皮毛和头部，不替换完整角色贴图。
- 开心表情使用弯眼和张嘴，受击使用闭紧的眼睛与皱嘴，专注表情具有压低的上眼线。眨眼使用专门的闭眼线条，沿用当前嘴型；眨眼节奏与走路速度分离。

| 游戏状态 | 自动表情 |
|---|---|
| 待机、行走 | 日常 |
| 攻击、施法 | 专注 |
| 接受治疗或友方支援演出 | 开心 |
| 受击 | 忍痛 |
| 倒下演出 | 闭眼 |

惊讶表情作为独立预览提供，目前没有绑定新的遭遇或剧情触发。

## 预览入口与维护

标题 → 基因图鉴 → **面部表情室**。五个物种各展示三种表情，底部切换两组；下拉菜单切换灵动、圆润、锐利三种脸型。也可从伙伴的形态工坊进入，使用伙伴基因的副本对照，实际角色不会被修改。

- `tools/creature_faces.py`：15 个头型、90 组眼部表情（5 物种 × 3 脸型 × 6 表情）、30 组嘴型。
- `scripts/creature_assembly.gd`：脸部选择、预缓存、眨眼和与头部一致的局部变换。
- `scripts/unit_motion.gd`：提供独立于步频的表情时钟。
- `scripts/face_workshop.gd`：放大查看运行时实际部件，与地图使用同一绘制逻辑。
- `python tools/create_creature_parts.py`：生成 `assets/creature_parts_v10/` 和内嵌 SVG 库。全部 219 个资源均为独立部件，每只角色实际绘制 11–14 个部件。

所有表情在组合角色时预缓存，技能演出中只选择已有纹理。相同虹膜在不同毛色角色间复用眼睛，嘴部纹理跨毛色复用。保留 96 个组合与 512 个部件纹理的缓存入口上限；旧 v0.8/v0.9 部件目录留作历史资料，不打包进入独立版。

## 验证结果

Godot 4.7.2 的八套回归测试共 **10,694 项通过，零失败**：规则 4,907、UI 103、控制 444、遗传技能 557、战斗深度 3,572、运行与操作缓存 46、环境美术 70、角色部件 995。

新增检查覆盖 219 个透明部件有效内容、五物种六套眼睛／嘴型确实不同、游戏动作与表情映射、眨眼保持嘴型、步频不影响眨眼时间、眼嘴与头部同步、反复切换表情不重新栅格化、跨毛色缓存复用、表情页与脸型选择不改真实伙伴。功能测试通过引擎控件与接口执行。

实机检查三种脸型、六组表情、完整角色、同色物种对照、地图尺寸、战斗 HUD、技能动画、图鉴入口与标题。截图位于 `screenshots/faces10_*.png`；技能连续帧位于 `screenshots/animation_frames/`。头部、眼睛、嘴部仍可随角色左右翻转，未新增八方向面部素材。

Windows 独立版已重新导出，最终 EXE 为 134,766,888 字节。独立版检查覆盖表情页、反应表情、角色整体、战斗、标题与锐利脸型；最后的下颌微调后重新运行部件测试（995 项通过），并复测导出包的锐利脸型与原 `启动游戏.bat`。启动器退出码 0，生成本次 `screenshots/faces10_launcher.png`；日志记录 `PREVIEW_CAPTURE faces 0`。没有脚本或素材加载失败。

性能采样：RTX 3060 Laptop GPU、Compatibility / OpenGL 3.3、1296×864 窗口、1440×960 逻辑分辨率，关闭 VSync，固定种子，每场景预热 30 帧再取 180 帧。城镇平均 **2.85 ms / P95 3.32 ms**，战斗平均 **2.55 ms / P95 2.86 ms**，日志 `diagnostics/benchmark_faces10.log`。这是本机固定负载结果，不代表所有硬件和长期游玩。

测试、预览和导出使用 `diagnostics/appdata` 隔离目录，真实玩家存档未改动。部分 headless 测试仍出现历史日志中已有的资源退出提示；图形预览与功能测试的脚本检查无失败。机器读取系统证书库的环境提示仍存在，离线游戏不使用联网功能。
