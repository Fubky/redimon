# v0.11 花叶设计与验证

本轮参考用户提供的白色圆润小兽、绿色背叶与粉色花朵图片，提取紧凑体态、大块自然特征、柔和配色和简洁五官，用原创 SVG 路径重新设计现有怪物。角色继续由独立部件和关节拼接；没有把参考图作为贴图，也没有用完整角色立绘替代基因组合。

## 造型与遗传

| 物种 | 本轮造型 |
|---|---|
| 绒耳猫 | 圆脸、短爪、花领与背部叶披，保留细长柔尾 |
| 旅风犬 | 长吻、深胸、层叠叶鬃与柔软蓬尾 |
| 团团鼠 | 圆耳、直立圆臀、小前爪和种荚背披 |
| 苔尾蜥 | 低伏宽身、多肉叶脊、叶片尾鳍与分趾爪 |
| 月纹蛇 | 连续曲颈、盘绕身体、花萼颈饰与头顶花芽 |

身体轮廓减少硬角，底色与奶油白混合，阴影采用较柔和的灰绿色，细描边统一为暖灰绿。眼睛比 v0.10 更收敛，减少虹膜暗圈和第二层高光；仍保留三种脸型、独立瞳色及六种表情。

新增 20 个植物器官：每物种各有四种毛质表达对应的形态。底色基因同时影响身体、叶色与花色，共感基因选择花朵或种荚。原有体型、肩高、骨量、肌肉、体长、耳型、尾型、花纹、白斑、对比和光泽仍可改变组合外观。没有改动基因数值、技能、种族值、捕获率或存档 schema。

花叶绑定身体、颈部或头部关节，随呼吸、步伐与技能动作轻摆。地图、队伍界面、标题、时间轴及预览使用同一套组合逻辑。

## 预览与维护

开始界面 → 基因图鉴 → **花叶物种图鉴**。五只样本支持待机、行走和施法，可进入形态工坊、同基因物种对照、20 种遗传形态与面部表情室。样本由真实的基因与渲染器生成；调整预览不修改玩家伙伴。

- `tools/creature_botanical.py`：圆润体型、柔尾、花叶、花朵和种荚的矢量部件。
- `tools/creature_faces.py`：头型、眼睛及嘴部的表情路径。
- `tools/create_creature_parts.py`：材质、描边和部件生成入口；运行 `python tools/create_creature_parts.py` 可复现当前库。
- `scripts/creature_assembly.gd`：基因配色、植物器官选择、连接、关节动画和缓存。
- `scripts/botanical_workshop.gd`：五物种完整造型预览。
- `assets/creature_parts_v11/`：239 个可编辑透明 SVG。角色实际绘制 12–14 个部件；眼嘴表情预热缓存，不在技能帧中生成 SVG。

旧 v0.8、v0.9、v0.10 素材目录继续保留作参考，Windows 导出排除这些旧目录。纹理与角色组合缓存继续有容量上限。

## 验证

Godot 4.7.2 八套回归检查共 **10,882 项通过，零失败**：规则 4,907、UI 103、控制 444、遗传技能 557、战斗深度 3,572、运行与操作缓存 46、环境美术 70、角色部件 1,183。

覆盖 239 个部件的有效透明内容、五物种四种植物器官确实有不同图像、遗传基因改变外观、所有动作下的花叶关节有效、花叶随身体运动、只读图鉴、表情和动画缓存。源工程实机检查包括整体花叶造型、行走、施法、20 种形态、表情、标题与战斗 HUD。

Windows 独立版重新导出，最终 `build/windows/GeneTrail.exe` 为 **134,818,528 字节**。独立版图形检查覆盖图鉴、面部表情、战斗移动、技能演出、图鉴入口和标题。最终原 `启动游戏.bat` 返回 0，日志记录 `PREVIEW_CAPTURE botanical 0`，生成本次 `screenshots/garden11_launcher.png`。

检查导出后的连续技能截图时发现旧诊断分支向只读 `res://` 写帧的问题，已改为在指定截图路径旁创建帧目录，并在目录或 PNG 写入失败时退出报错。最终导出包成功保存 24 张技能帧，位于 `screenshots/garden11_packaged_animation_frames/`，最终截图与日志均返回 0。

实际截图：`screenshots/garden11_*.png`；独立包截图：`screenshots/garden11_packaged_*.png`。最终启动器图鉴图为当前版本的完整造型展示。

性能采样环境：RTX 3060 Laptop GPU、Compatibility / OpenGL 3.3、1296×864 窗口、1440×960 逻辑分辨率，关闭 VSync，固定种子，每场景预热 30 帧后采样 180 帧。城镇平均 **3.30 ms / P95 4.17 ms**，战斗平均 **3.00 ms / P95 3.75 ms**，记录在 `diagnostics/benchmark_garden11.log`。这组数据是本机固定负载采样，不作为跨设备性能承诺。

测试、预览与导出均使用 `diagnostics/appdata` 隔离目录，未修改真实玩家存档。机器仍报告系统证书库读取提示，部分 headless 测试保留历史资源退出提示；最终图形预览没有脚本、资源加载或截图写入失败。角色仍为侧向骨架与左右翻转，没有新增完整八方向素材。
