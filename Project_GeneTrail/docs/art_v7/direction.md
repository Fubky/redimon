# v0.7 美术方向

目标：以《磁带妖怪》原作的完成度为参照，统一为清晰像素角色、带高度的地形、材质明确的建筑和受控光色。保持本作随机 TileMap、基因外观、自由探索及时间轴战棋结构。

参考来源：[官方原作资料与截图](https://www.cassettebeasts.com/cb1-presskit/)。仅用作风格分析，游戏资源均为本项目原创生成或代码绘制。

主要改动：5 类物种 × 4 个动画帧的透明角色图集；4 座可区分的城镇建筑；16 类环境道具；5 套低噪声地形与侧壁；柔化探索边缘；动态光色、接触阴影和环境粒子；统一深靛蓝、青绿、琥珀的 UI 与战斗特效。场景中的角色、HUD 和图鉴使用同一套基因外观。

新素材通过内置 image_gen 生成。完整提示词记录在 prompts.json 与各 *-prompt.txt，对应关系见本目录 README.md；原始 PNG 保留在 assets/art_v7，角色与物件图集保留 alpha。
