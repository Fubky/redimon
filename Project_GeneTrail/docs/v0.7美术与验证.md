# v0.7 美术重制与验证

## 已接入游戏的内容

- 标题主视觉、五物种角色图集、四座城镇建筑、20 类环境物件和五套地下城材质。角色与建筑按脚底 Y 坐标排序，支持建筑前后遮挡。
- 城镇石板路、池塘、树木、花丛、灯具与围栏；地下城按地形放置植被、岩石、棕榈、珊瑚、熔岩和晶体。宝箱与楼梯改用独立物件素材。
- 基因外观统一用于实际单位、队伍头像、基因手记和问答结果。待机、行走与技能姿态使用图集，受击、治疗、倒下和前冲继续由动作控制器驱动。
- 柔化探索视野、低频云影、暖色光和单位接触阴影。特效增加弹道尾迹、近战三道斩痕、元素碎片、时序钟面与局部柔光。
- 标题页与探索、战斗 HUD 统一深靛蓝、青绿和琥珀；保留可读性优先的 AP 蓝／橙色行动范围、高对比技能浮窗和清楚的时间轴。

本轮保持既有 2D TileMap 架构。以[《磁带妖怪》官方画面](https://www.cassettebeasts.com/cb1-presskit/)为完成度参照，最终观感以实机截图为准；未将商业成品的整体美术水准作为已验证结论。

## 性能设计

地表和环境道具保留静态绘制结果，角色由逐帧矢量绘制替换为基因图集纹理。每种基因外观只计算一次，地图建立时预热；缓存上限 96 个基因图集。移动、HUD、范围和寻路延续 v0.6 的缓存机制。氛围是一个轻量 CanvasItem 着色器，视野纹理仅随探索状态变化更新。

本机为 AMD Radeon Graphics，1440×960 逻辑分辨率、1296×864 窗口；VSync 关闭，固定种子 170930，每场景预热 30 帧、采样 180 帧。与 v0.6 使用相同脚本及配置；只代表本机固定场景，不能外推到所有设备、地图或技能演出。
