# v0.14 混合血统与共用基因

日期：2026-10-02。工程与 Windows 包均使用 Godot 4.7.2。

## 游戏规则

角色不再具有决定玩法的固定种族。每人保存灵长人、翼人、龙人、兽人、鱼人、蛇人、角人七项家系来源，合计 100%，精度 0.01%。新存档只保存 `bloodline`，不写入 `species` 或旧的二编号 `ancestry`。

后裔血统为两位亲本的完整比例各取一半。例如，翼人 50% / 角人 50% 的亲本与兽人 100% 的亲本结合，后裔为翼人 25% / 角人 25% / 兽人 50%。整数基点与最大余数补齐确保长期传承仍合计 100%；更换双亲顺序不会改变结果，最多产生 0.01% 的舍入差。

所有角色共用 25 个双等位基因位点：原有 18 项，加上统御、羽翼、龙鳞、兽征、鱼尾、蛇尾、角冠七项特征表达。血统记录来源，基因独立重组；拥有某项血统并不保证表达特征，缺少某项来源也不会禁止携带其特征基因。生成角色时按背景设置初始表达，敌人另外有共享潜在等位基因，因此同样血统可以出现不同外形。

每个特征表达为两条等位基因的均值，达到 40 时开放对应初阶技能，达到 Lv.8 再开放进阶技能。七组原种族技能全部进入共用基因池，不再检查种族或血统占比。25 个位点各有两个潜在技能条目，加上四项共同战术和三项当前职业技能，合计 57 个目录条目；实际开放受表达、等级和职业熟练度限制，最多携带四项。

所有位点仍从每位亲本各取一条等位基因，每条有 2.5% 突变概率。职业、职业经验、等级和努力值不遗传。亲属、床位和金币限制保留。

基础属性中的来源底值和普通招募基础率按七项血统完整加权。例如灵长人 50% / 鱼人 50% 的基础招募率为 15%，再应用已有等级、印记与徽记等加成；守望者仍使用其精英规则。战斗属性由最强的两个已表达特征决定；不足两种时保留原有光泽 / 颜色补充规则。特性改由共感、肤纹和发型组合决定。

## 拼装与操作

- 创建角色：点击「编辑七项血统比例与表达」，左侧编辑比例，右侧独立调整共用特征位点。调整一个比例后，其余按原比例分配余量；只有一个来源时，剩余量分给灵长人，或从灵长人分给翼人。
- 「从当前血统生成表达」是可选的起点设置；单独改变血统不会覆盖基因。弹窗编辑使用草稿，只有「应用血统与基因」才写入，返回 / Esc 会取消。
- 档案：显示血统概况，点击「血统比例与共用基因」查看完整七项；25 项双亲等位基因支持滚动查看。技能界面优先显示已携带和已解锁技能，并显示缺失的表达阈值。
- 家系馆：在确认前显示预期后裔的完整血统比例。共用基因照常重组，预期血统不等于预设外观。
- 角色名录：六个混合案例，覆盖七项来源与三职业，支持行走和施技预览。角色仍由独立部件拼接。

羽翼、鳞片、耳爪和角可以同时出现。鱼尾与蛇尾互斥，取较强表达，平值优先鱼尾；它们会替换腿脚和普通尾巴。鸟翼与龙翼互斥，平值优先鸟翼，龙翼仍需要背部表达至少 60。兽尾与蜥蜴尾互斥，平值优先蜥蜴尾。外形缓存仅依赖基因与职业，修改血统不会把已表达部件强行替换。

## 兼容与验证

存档版本升级为 v5，保留原来的用户存档路径。v1—v4 可读取：旧单种族转为 100% 对应来源；旧谱系 `[1,6]` 转为翼人 50% / 角人 50%，不再丢弃较大编号。缺失的七项新基因按旧谱系补齐，再进入共用表达规则；原角色、家系关系、资源、职业、债务、任务与副本状态保留。下一次保存写为 v5。

新版本严格校验七项非负整数基点、合计 10000 以及完整 25 位点；无效占比、非有限值、缺失血统和缺失新位点不会被静默接受。旧动物预览脚本保留的 `species` / `ancestry` 仅作为兼容字段，不参与当前人形渲染、技能、属性、招募或遗传规则。

回归入口 `tools/verify.ps1`，包含十组检查。新增 `tests/test_bloodline.gd` 验证 200 代比例守恒、双亲对称、共同技能开放、多特征拼装、互斥部位、潜在基因分离、实际后裔、旧版迁移、非法存档与混合敌人生成。UI 检查包括草稿取消、从血统生成表达、跨血统自由配置特征，以及创建后的保存与进入游戏。

所有自动测试、性能测试和预览使用 `diagnostics/appdata` 隔离目录，未删除或改写真实玩家存档。
