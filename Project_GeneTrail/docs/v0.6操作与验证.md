# v0.6 操作与性能验证

## 操作变化

- 我方回合自动选中行动角色，直接显示移动范围与行动栏。连续两次轮到同一角色也会重新选中。右键 / Esc 可取消选择；普通界面刷新不会强行恢复选择。
- 移动每格 8 AP，按实际路径计算。蓝色表示累计消耗不超过 50 AP；橙色斜线表示超过分界，路径中的超出部分也变为橙色。悬停显示移动格数、消耗、剩余 AP、额外延后刻数和预计回归位置。
- 例如已用 35 AP，再走两格需要 16 AP，累计 51 AP，通常会额外延后 70 刻。已在爆发区时提示当前预计回归时间，不重复宣称又增加 70 刻。时间计算仍采用原有规则及至少 12 刻的下限。
- 技能浮窗使用不透明深色背景、浅色文字、18 像素正文和自动换行，分开显示名称、AP、射程、目标、效果、来源、冷却和越界提示。正文区域宽 440 像素，原生浮窗自动避开窗口边缘。
- 地下城支持长按 WASD / 方向键连续行走，松开停止，每步约 0.14 秒。点击目的地只规划一次路线，方向输入可覆盖路线；进入战斗、打开菜单或切换领队时停止自动前进。转弯动画沿路线拐点走，战斗中方向键仍只移动镜头。

## 性能处理

静态城镇建筑、花园与地下城墙体阴影单独保留绘制结果；角色椭圆渐层由 32 次三角形绘制改为一次顶点颜色插值绘制，并复用圆周顶点。角色基础属性、遗传技能池和配招验证缓存会在基因、等级、物种或配招变化时失效。

视野只在地图或存活队友位置变化时重算。战斗移动范围和技能射程复用缓存；悬停路线只在目标或相关状态变化时重新寻路，AP 预览直接读取同一移动范围的距离。时间轴、小地图按状态变化重绘。探索位置变化不会销毁并重建 HUD，资源、生命、回合等变化仍正常更新。

## 本机对照

Godot 4.7.2，Compatibility / OpenGL 3.3，AMD Radeon Graphics，1440×960 逻辑分辨率、1296×864 窗口。测试脚本 `tests/benchmark_runtime.gd` 使用固定种子 170930、静止镜头，关闭垂直同步和帧率上限，每场景预热 30 帧、采样 180 帧。结果反映本机固定场景，不代表所有设备或所有战斗的帧率。

| 指标 | 修改前 | 修改后 |
|---|---:|---:|
| 城镇平均帧耗时 | 95.10 ms | 7.71 ms |
| 城镇 P95 帧耗时 | 112.70 ms | 10.14 ms |
| 战斗平均帧耗时 | 25.66 ms | 5.99 ms |
| 战斗 P95 帧耗时 | 33.55 ms | 9.56 ms |
| 2,000 组属性 / 技能查询 | 726.930 ms | 9.393 ms |
| 100 次无状态变化的刷新 | 855.752 ms | 7.849 ms |

原始记录：`diagnostics/benchmark_before.log` 与 `diagnostics/benchmark_final.log`。

## 验证

`tools/verify.ps1` 共通过 9,629 项断言：规则 4,907，UI 103，控制 444，遗传技能 557，战斗深度 3,572，操作与缓存回归 46。新增检查包含 30 / 60 / 120 FPS 长按移动一致性、键盘覆盖点击路线、遇战中断、转角动画、50 AP 精确边界、已有爆发状态、相邻两次同角色回合、缓存失效和技能浮窗文字对比度大于 7:1。

图形检查包含城镇、战斗移动延后预览、实际悬停技能浮窗。截图位于 `screenshots/town_v6.png`、`screenshots/battle_move_v6.png`、`screenshots/battle_tooltip_v6.png`。测试存档隔离在 `diagnostics/appdata`；正常游戏存档格式仍为 v3。
