# 帝国佣兵 · 血脉与契约 v0.15

Godot 4.7.2 的可玩原型。在原有城镇探索、随机地下城和时间轴战棋玩法上，改为神圣罗马帝国诸邦背景的幻想佣兵故事。

双击 **启动游戏.bat** 游玩。启动器优先运行 **build/windows/GeneTrail.exe**；编辑工程请打开 **project.godot**。

## 本版内容

- 血统编辑使用七条联动滑条，总和始终为 100%。初始角色默认自动生成性状，并在弹窗内实时预览；手动编辑右侧基因会切换为自由模式，仍可跨血统配置共用基因。
- 新增三种本次远征战术：协同追击鼓励队友接力，轻装轮替奖励低 AP 行动与战后续航，破阵强攻为超支攻击提供一次爆发收益。目标预览显示加成和时间轴位移。
- 可选高危悬赏：敌人等级 +2，击杀金币 ×1.5，完成三层额外 +120 金币。战术与风险在出征前选择，持续到返城。

- 每个角色拥有七项血统占比：灵长人、翼人、龙人、兽人、鱼人、蛇人、角人，合计 100%。没有固定种族，所有来源共用 25 个双等位基因；羽翼、鳞片、兽耳、角等特征可以同时表达。
- 骑士、魔法师、游侠 / 战士三种职业，对应板甲长剑、法袍法杖、皮甲短弓。城镇免费转职，保留各职业熟练度。当前职业决定技能池与装备部件。
- 49 个独立 SVG 部件，包括帽子、头发、脸部、躯干、手臂、手掌、腿、脚、背部、武器与种族附肢。肤色、发色、脸型、发型、角 / 耳型、尾 / 羽型、体型与身高受遗传表达影响。没有整个人物的固定立绘。
- 标题 → 进入游戏 → 新建旅程 → 自定义角色。点击「编辑七项血统比例与表达」，分别设置血统和共用特征基因；也可设置职业、姓名、体质天赋与外观。初始仍为主角和莉泽两名佣兵。
- 主线为偿还继承的 **3000 金币债务**。任务栏可分期或尽力还款，不设倒计时与自动扣款；全部清偿后主线完成，仍可继续游玩。
- 任务栏共有 **10 份委托**：五个区域各有一份清剿和一份护送，随副本递进解锁。清剿需击败指定区域 4—8 个敌人；护送需将独立委托人从第 1 层入口带至第 2 层楼梯。达成后回镇交付，奖励仅发放一次。

## 职业与遗传

在 **队伍 → 成长培养 → 转职与职业训练**，或角色档案底部进入职业教官。骑士以骨量、肌肉见长；法师以共感、以太传导见长；游侠以敏捷、肢体比例见长。基因使职业所需熟练度在 ×0.75—1.35 之间变化，任何血统都能学习任何职业。

战斗和委托经验同时增加当前职业熟练度。花费 30 金币可训练 30 熟练度；达到 R1 / R2 / R3 分别开放三项职业技能，R2—R5 继续增加相应实战攻防或速度。转职免费，旧职业的进度保留，当前四技能会重新配备。七组特征天赋已进入共用基因池：表达值达到 40 时开放初阶，Lv.8 再开放进阶，不受血统占比限制。

25 个双等位基因各自提供初阶与进阶技能。共用基因、共同战术和当前职业合计 57 个潜在技能条目，表达、等级与职业熟练度决定解锁，最多携带 4 项。大体型偏向延时，小体型偏向低 AP。技能、属性克制、状态、AI、天气与时间轴继续使用原有规则。

在 **家系 / 遗传** 选择两名非近亲成年佣兵，花费 60 金币并预留一个床位，模拟下一代并快进至成年登记入团。每个位点各取双亲一个等位基因，有 2.5% 的等位变异概率。血统比例各取双亲一半并合并同名来源，精确到 0.01%，长期传承始终合计 100%。基因独立重组，不再由较小种族编号决定后代。职业、职业经验、等级和努力值不遗传。

出征最多四人；招募溢出者回营舍，所有已拥有角色占床位，满员需扩容。新成员仍通过概率投诚，七项来源的基础率为 25 / 18 / 12 / 8 / 5 / 10 / 16%，按全部血统占比加权，保留原有等级、天赋、印记与通行徽记修正。

## 委托操作

城镇右下角 **任务栏 / 贷款** 或走近广场实体任务栏按 E。左上角常驻条也能查看债务与委托进度。最多同时承接三份，其中护送最多一份；区域未解锁时不能接取。

- 清剿进度可跨远征累积，倒下的同一敌人只计数一次；已经完成的委托不能再次领取报酬。
- 护送人不占四人队伍槽，也不由玩家控制。其会跟随队伍、在开战时集合到同房间，能被敌人攻击，能接受治疗和守护。其异常状态在每次敌方行动结束时结算。
- 抵达第 2 层楼梯后按 E；委托人必须存活并位于六格以内。护送完成后可继续第 3 层或回城交付。
- 正在护送时撤退或委托人倒下会使任务失败，可回城免费重接。任务已达成后的返程不会撤销成果。
- 清剿奖励 220—620 金币，护送奖励 360—840 金币；额外发放小队经验和职业熟练度。

## 操作

| 输入 | 功能 |
|---|---|
| 城镇 WASD / 方向键 | 连续自由行走，可斜向移动 |
| 探索 WASD / 点击地面 | 连续逐格探索 / 自动寻路 |
| 战斗 WASD | 移动镜头；C 回正 |
| 我方回合点击空格 | 自动选中当前角色后，点击蓝色 / 橙色移动范围 |
| 战斗 1 / 2—5 | 移动 / 四个已携带技能 |
| 空格 | 结束行动 |
| E | 附近设施互动 / 楼梯下层与护送交付 |
| Q | 使用药草 |
| Tab / G / 滚轮 | 总览 / 格线 / 缩放 |
| F1 / F11 | 手册 / 全屏 |

每次行动获得 100 AP，移动每格 8 AP。累计消耗超过 50 AP 后，下次回归时间增加 70 刻；橙色格线和 HUD 会提前提示。进入敌人所在房间开战，清空本房间即脱战。五种随机地下城依次解锁：森林、山地、海岛、火山、洞窟。

## 存档与开发

旧 v1—v4 槽位可以读取；新存档为 v5。旧单种族转换为 100% 对应来源，旧双谱系转换为各 50%，缺失的七项特征基因按旧谱系补齐。角色、家系、职业、资源、债务、委托和副本状态保留。存档目录继续使用 `%APPDATA%/Godot/app_userdata/萌芽远征 · Gene Trail/slots/`，不会删除已有进度。

- `tools/verify.ps1`：导入与十二组回归测试；所有测试存档隔离在 `diagnostics/appdata`。
- `tools/build_windows.ps1`：使用本地 Godot 4.7.2 和配套模板导出 Windows 包。
- `tools/create_human_parts.py`：生成独立 SVG 与运行时部件库。
- `scripts/human_assembly.gd`：缓存、拼装、关节动画与头像。
- `scripts/mercenary_rules.gd` / `contract_rules.gd`：职业与委托规则。
- `scripts/bloodline.gd` / `bloodline_ui.gd`：血统遗传、创建与档案界面。
- `scripts/expedition_rules.gd` / `expedition_ui.gd`：出征战术与高危悬赏。
- 本轮规则与验证见 `docs/v0.15出征战术与角色创建修复.md`；混合血统底层说明见 `docs/v0.14混合血统与共用基因.md`。

本版沿用原有五域环境资产与原创背景音乐。背景是带亚人和魔法的帝国幻想题材，职业衣装由模块绘制，当前没有独立装备掉落或装备背包系统。
