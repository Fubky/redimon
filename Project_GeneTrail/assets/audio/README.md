# 原创音频清单

全部旋律、伴奏音序、音色合成与事件音效由本项目 `tools/create_audio.py` 新制作。未下载第三方录音、SoundFont，未使用《宝可梦不可思议迷宫》等作品的旋律或采样。音乐方向为明亮、温暖的迷宫探险：木管主旋律、钟琴、拨弦、柔和铺底、轻打击乐。

| 文件 | 场景 | BPM |
|---|---|---|
| title.wav | 标题／问答 | 92 |
| town.wav | 家园与城镇 | 104 |
| forest.wav | 森林 | 112 |
| mountain.wav | 山地 | 98 |
| island.wav | 海岛 | 108 |
| volcano.wav | 火山 | 118 |
| cave.wav | 洞窟 | 84 |
| battle.wav | 时间轴战斗 | 138 |

每段音乐为 16 小节立体声循环，共约 294 秒；22,050 Hz / 16-bit PCM。混响尾音环绕到循环起点，极短边界淡化避免爆音。`manifest.json` 记录每个文件的长度、峰值与 RMS。

音效：UI、脚步、命中、施法、治疗、延时、进入战斗、倒下、胜利、升级、保存、招募，共 12 种。游戏提供独立 Music／Effects 总线和音量设置，切换场景使用两个播放器交叉淡化。

音频资产随本项目一同提供，可在本游戏中使用和修改。重新生成需要 Python 与 NumPy，不需要额外音乐插件。
